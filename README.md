# 🌱 Farm-Xpert - Smart Farming Prediction System

Farm-Xpert is a Smart Farming Prediction System developed using Machine Learning and Streamlit. The application helps farmers make better agricultural decisions by providing predictions and recommendations related to crops, soil, yield, fertilizer, profit, irrigation, weather, and government schemes.

## 🚀 Features

- 🌾 Crop Prediction
- 🌱 Soil Analysis
- 📈 Crop Yield Prediction
- 🧪 Fertilizer Recommendation
- 💰 Profit Estimation
- 💧 Irrigation Recommendation
- 🌦️ Weather Information
- 🏛️ Government Schemes Information
- 🌐 Multi-language Support
  - English
  - Hindi
  - Telugu

## 🧠 Machine Learning

The system uses Machine Learning algorithms to analyze agricultural data and provide predictions based on different input parameters.

The prediction process considers factors such as:

- Soil Type
- Temperature
- Humidity
- Rainfall
- Land Area
- Crop Details
- Fertilizer Requirements

## 📂 Project Features

### 🌾 Crop Prediction

Users can provide agricultural conditions such as soil type, temperature, humidity, and rainfall to get suitable crop predictions.

### 📈 Yield Prediction

The system predicts the expected crop yield based on agricultural input data.

### 🧪 Fertilizer Recommendation

The application recommends suitable fertilizer information based on crop and soil conditions.

### 💰 Profit Estimation

Farmers can estimate potential profit based on:

- Crop
- Land Area
- Production Cost
- Expected Yield
- Market Price

### 💧 Irrigation Recommendation

The system provides irrigation recommendations based on crop and environmental conditions.

### 🌦️ Weather Information

Users can access weather-related information useful for agricultural planning.

### 🏛️ Government Schemes

The application provides information about government schemes that may benefit farmers.
